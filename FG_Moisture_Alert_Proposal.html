Latar Belakang & Problem Statement

Finish Good (FG) yang disimpan terlalu lama di gudang berisiko mengalami peningkatan moisture yang dapat mempengaruhi kualitas produk. Saat ini tidak ada sistem otomatis untuk mengingatkan tim Quality Control.

❌ Kondisi Saat Ini
  • Pengecekan moisture dilakukan manual tanpa reminder
  • Tidak ada tracking PO mana yang sudah/belum di-check
  • Risiko terlewat PO yang sudah lama di gudang
  • Data hanya di Excel tanpa alert system
✅ Solusi yang Diusulkan
  • Alert otomatis ke WA Group saat PO sudah 3 minggu di FG
  • Dashboard monitoring status pengecekan moisture
  • Reminder otomatis jika belum di-check dalam 3 hari
  • Pencatatan hasil moisture check dengan threshold otomatis

🔔 Alert Trigger
PO usia ≥ 21 hari (3 minggu) sejak SI DATE
⏳ SI DATE Kosong
Status WAITING FOR SI — belum mulai countdown

≥ 15% = FAIL ❌  |  < 15% = PASS ✅
🔄 Reminder
3 hari setelah alert pertama jika belum di-check
⏰ Jadwal Alert
Setiap hari jam 08:00 WIB

Aliran data dari input (Excel) → processing (backend) → output (WhatsApp + Dashboard).

Data yang sudah pernah di-upload akan otomatis di-skip berdasarkan PO Number + No. Carton.

Parse Setiap Row

Cek Duplikat
PO + NO.CTN sudah ada → SKIP  |  Belum ada → INSERT
4
Hasil Upload
"Upload selesai — 120 rows baru ditambahkan, 5.878 rows di-skip"

PO yang sudah lewat 3 minggu dari SI DATE saat sistem pertama kali jalan langsung di-mark SKIPPED — tidak ada alert spam.

🗄️ Database Schema
-- Tabel PO (1 row per PO) CREATE TABLE po_data ( po_number TEXT UNIQUE, article TEXT, market TEXT, customer TEXT, warehouse TEXT, qty_order INTEGER, start_in_fg DATE, si_date DATE, -- ⭐ trigger (SI DATE) status TEXT -- WAITING_SI / WATCHING / ALERTED / CHECKED / SKIPPED ); -- Tabel Carton (dedup key: PO + carton number) CREATE TABLE cartons ( po_number TEXT, ctn_number INTEGER, UNIQUE(po_number, ctn_number) -- ← DEDUP KEY ); -- Tabel Alert & Moisture Check CREATE TABLE alerts (po_number TEXT, alert_type TEXT, sent_at DATETIME); CREATE TABLE moisture_checks ( po_number TEXT, checked_by TEXT, moisture_value REAL, -- ≥15% FAIL, <15% PASS result TEXT, remarks TEXT, check_date DATETIME );
